# Creative-Coding-Ashmira-Gupta-

This is my game called everland. Press space to begin! Use your arrow keys to move around and interact with the different characters and music houses, collect tokens and visit all music houses to complete the game! Find the secret missions to collect as many tokens as possible <3 

Files in the data section include the map, sprite and music files. 

This game is very personalised to my own interests and aesthetics, and I spent a lot of time thinking about how to incorporate my interests and hobbies into this subject and create a piece of code that I am not only interested in, but also felt passionate and excited to create. I hope you love playing this game as much as I do!
